# Радиотехнические цепи и сигналы

В этом гитхабе собраны материалы по курсу РТ цепей и сигналов - конспекты лекций, методички, дополнительные материалы. 

Ссылки на **записи лекций**: 
* 2026 год: [лекторий ФРКТ](https://www.youtube.com/playlist?list=PLEXtgMOJOHcQ)
* 2025 год: [старые записи](https://youtube.com/playlist?list=PLyTXBGgIaXM7SLXLpisSV7FjajfhnntsB&si=M-ZGVAL-Lug5fV3-)

Лекции постоянно обновляются, поэтому рекомендуем смотреть самый последний год.

Курс разбит на 5 тем, каждой теме соответствует своя директория. При чтении советуем скачивать pdf, так как в режиме предпросмотра не работают внутренние ссылки и может скашиваться верстка.
